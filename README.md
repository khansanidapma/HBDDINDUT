# HAPPY UJANG DAY YEAY 🎂

Birthday mini website untuk 2 Oktober.

## Isi
- Intro "SELAMAT ULANG TAHUN UJAAAANG!!" dengan efek pop + confetti
- Pop-up book / surat interaktif
- 3 foto utama dengan efek hover/select
- Gallery foto random
- Caption jas hujan: "with other bestieee ( barbiee )"
- Closing wish: "semoga hidup selalu sekian terima gaji"
- Soundtrack lokal `assets/birthday-song.mp3`
- Favicon kue ulang tahun
- Custom cursor berbentuk lilin menyala di desktop
- Responsive untuk HP, tablet, dan laptop

## GitHub Pages
Upload seluruh isi folder/ZIP ini ke repository. Pastikan `index.html` ada di root folder yang dipublish oleh GitHub Pages.

Catatan: browser biasanya mengizinkan audio otomatis setelah pengguna melakukan klik. Karena itu soundtrack dimulai saat tombol "BUKA HADIAHNYA" ditekan.
